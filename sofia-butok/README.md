# Сайт Софії Буток — репетиторка з української мови та історії України

Односторінковий сайт без збірки: просто відкрий `index.html` у браузері або завантаж папку на будь-який хостинг (GitHub Pages, Netlify, Vercel).

## Що налаштувати

- **Фото:** `sofia.jpg` поруч з `index.html` (щоб замінити, просто поклади новий файл з тією ж назвою).
- **Контакти:** Telegram — `@a_sonchikk` (`CONFIG.telegram` у `<script>`), Instagram — `@a.sonichka` (`CONFIG.instagram`).
- **Заявки з форми:** після надсилання кнопка «Відкрити Telegram» відкриває чат з @a_sonchikk з уже вставленим текстом заявки (посилання `t.me/a_sonchikk?text=…`). Учню лишається натиснути «Надіслати». Текст також копіюється як запасний варіант.

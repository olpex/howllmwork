# Сайт Софії Буток — репетиторка з української мови та історії України

Односторінковий сайт без збірки: просто відкрий `index.html` у браузері або завантаж папку на будь-який хостинг (GitHub Pages, Netlify, Vercel).

## Що налаштувати

- **Фото:** поклади фото у файл `sofia.jpg` поруч з `index.html`, і воно автоматично заміне ініціали «СБ» у головному блоці.
- **Контакти:** на початку `<script>` в `index.html` заповни `CONFIG.telegram` та `CONFIG.instagram`.
- **Заявки з форми:** зараз форма показує «Дякую!» і пише заявку в консоль. Щоб заявки приходили, підключи Telegram-бота або сервіс на кшталт Formspree (місце позначено `TODO`).
